# unJSON
unJSON is a utility which takes formatted JSON files and returns flattened, unformatted versions, excluding spaces and indentations outside of strings. 

This tool was originally created for the Minecraft: Bedrock Edition commands development community, where rawtext JSON in commands should be unformatted at runtime.

# How To Install
Simply run this command in the terminal:
```bat
npm i -g @maxedout4826/unjson
```

# How To Use
Run this command once in the project root to begin watching for file changes:
```bat
unjson watch
``` 
When this command is ran, unJSON will create a new 'unjson' folder in your project's root, which contains the 'input' and 'output' directories; you should not change these directory names.

unJSON will wait for new JSON files to be added, or updates to be made to exiting JSON files within the input directory.

If the new or updated file uses correctly formatted JSON (comments not yet supported), a new file will be created under 'output' containing your flattened and unformatted JSON; do not edit this file.
